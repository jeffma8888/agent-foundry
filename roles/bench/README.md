# The bench

Versioned role-cards for every seat the foundry knows how to staff -- most of
them dormant. The kickoff council activates the minimum set per product via a
staffing manifest; everything else waits for its written trigger.

See [`docs/ORG_DESIGN.md`](../../docs/ORG_DESIGN.md) for the full model:
rich bench -> cheap kickoff council staffs the minimum -> lean always-on core
-> trigger/cadence-activated specialists -> bounded re-staffing.

Card format (every card declares all five):
**Mission** . **Activation trigger** . **Tenure** . **I/O contract** . **Model note**

The bench is extensible: a council or re-staffing review that finds a gap
(e.g. a Security Reviewer) mints a new card here rather than overloading an
existing seat. New roles enter dormant by default.
